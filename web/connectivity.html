Database Connectivity (JDBC & ODBC)

Demonstration of genuine Java JDBC and Windows ODBC database drivers communicating with Oracle Database 11g XE

A. JDBC: Java to Oracle Database

NOT TESTED
Implementation Steps:
  1. Verify Windows services OracleServiceXE and OracleXETNSListener are running.
  2. Place the Oracle JDBC driver (ojdbc6.jar) in the project lib/ folder.
  3. Configure the thin JDBC URL, username, and password in config/db.properties.
  4. Launch the Java HTTP backend (com.bankloan.Main).
  5. Execute query via JDBC PreparedStatement and verify metadata.

Connection Parameters & Output:

  • Connection URL: jdbc:oracle:thin:@localhost:1521:xe
  • JDBC Driver: Oracle JDBC Driver (11.2.0.2.0)

B. ODBC: Windows to Oracle Database

NOT TESTED
Implementation Steps:
  1. Open Windows 64-bit ODBC Data Source Administrator (odbcad32.exe).
  2. Confirm that the Oracle in XE driver is installed.
  3. Configure the User DSN named OracleXE_PAT4.
  4. Execute the PowerShell ODBC test script (test_odbc_connection.ps1).
  5. Verify the connection using .NET System.Data.Odbc.

C. Simple Explanation for Practical Viva

What is JDBC? (Java Database Connectivity)

JDBC is a Java-based API that enables Java programs to execute SQL statements and interact directly with relational databases like Oracle. It uses a Type 4 thin driver (ojdbc6.jar) to communicate with the database over network sockets (port 1521) without requiring native software installation on the client.

What is ODBC? (Open Database Connectivity)

ODBC is an open standard interface provided by Microsoft Windows that allows applications to access databases using an ODBC driver. In this project, a 64-bit Windows Data Source Name (DSN) named OracleXE_PAT4 is configured using the Oracle in XE driver to demonstrate native operating system connectivity.
